## 🧠 Overview

**Plex-Earth** is an AutoCAD add-on designed to bring real-world geographic information directly into CAD workflows. It allows users to integrate satellite imagery, terrain data, and mapping services into their design environment without switching platforms.

The plugin helps bridge the gap between conceptual drawings and real-world site conditions by placing georeferenced data directly into AutoCAD projects. This improves early-stage planning accuracy and supports better design decisions.

By connecting CAD drawings with live geospatial sources, Plex-Earth streamlines the process of understanding terrain, context, and site layout. It is especially useful for infrastructure planning, civil engineering, and large-scale design projects.

---

## 🚀 Key Features

| Feature | Description |
|----------|-------------|
| 🗺️ **Satellite Imagery Import** | Bring high-resolution aerial images into AutoCAD. |
| ⛰️ **Terrain & Elevation Data** | Generate surfaces and contour models from real-world data. |
| ⏳ **Historical Imagery (Timeviews)** | Analyze how a site changes over time. |
| 📍 **Georeferenced Placement** | Align all data accurately to real-world coordinates. |
| 🔄 **Direct CAD Integration** | Work inside AutoCAD without external switching. |
| ⚡ **Fast Data Access** | Load maps and terrain with minimal setup time. |
| 🧠 **Context-Aware Design** | Design based on actual site conditions. |
| 🔗 **Multiple Data Sources** | Supports various global map providers. |
